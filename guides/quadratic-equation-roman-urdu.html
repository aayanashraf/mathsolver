Quadratic Equation Kaise Solve Karein (Roman Urdu Guide)

Quadratic equation woh hoti hai jis ka form ax² + bx + c = 0 ho, jahan a zero nahi hota. Ise solve karne ke do aam tareeqe hain: factoring aur quadratic formula.

Quadratic formula

x = (-b ± sqrt(b² - 4ac)) / (2a)

Pehle discriminant nikalein: D = b² - 4ac

  • D > 0: do alag real roots
  • D = 0: sirf ek (repeated) root
  • D < 0: real roots nahi hote (complex roots aate hain)

Misaal: x² - 5x + 6 = 0

  1. Values likhein: a = 1, b = -5, c = 6
  2. Discriminant: D = (-5)² - 4(1)(6) = 25 - 24 = 1
  3. Formula lagayein: x = (5 ± sqrt(1)) / 2 = (5 ± 1) / 2
  4. Nateeja: x = 3 ya x = 2
  5. Check: 3² - 5(3) + 6 = 0 aur 2² - 5(2) + 6 = 0, dono sahi hain

Factoring se

x² - 5x + 6 ko (x - 2)(x - 3) likha ja sakta hai, is liye x = 2 ya x = 3. Factoring tab aasan hai jab do numbers mil jayein jin ka product c aur sum b ho.

Khud try karein

x² + 2x - 8 = 0 solve karein. Jawab: (x + 4)(x - 2) = 0, to x = -4 ya x = 2.
