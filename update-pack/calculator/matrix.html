Matrix Calculator

Add, subtract, multiply or transpose matrices with the working shown.

About this calculator

Matrix operations follow strict size rules. This calculator checks them for you, then shows the result and how a typical entry is built.

How to use it

  1. Type matrix A and, if needed, matrix B, with rows separated by semicolons.
  2. Choose the operation.
  3. Read the result and the size warnings if the sizes do not match.

Example

1,2;3,4 times 5,6;7,8 gives 19,22;43,50.

Common questions

When can I multiply two matrices?

When the number of columns in A equals the number of rows in B.

Is A × B the same as B × A?

Not usually. Matrix multiplication is not commutative.

What is a transpose?

Swapping rows and columns.
