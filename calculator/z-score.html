Z-Score Calculator

Convert a value to a z-score and see its percentile.

About this calculator

A z-score says how many standard deviations a value is from the mean. It lets you compare values from different data sets on the same scale.

How to use it

  1. Enter the value, the mean and the standard deviation.
  2. Read the z-score formula applied.
  3. See the approximate percentile.

Example

x = 85, mean 70, standard deviation 10: z = 1.5, about the 93rd percentile.

Common questions

What does a negative z-score mean?

The value is below the mean.

What is a normal z-score range?

Most values in a normal distribution fall between −2 and 2.

Is the percentile exact?

It is an approximation that assumes the data is roughly normally distributed.
