Logarithm Calculator

Evaluate a logarithm of any base using the change of base formula.

About this calculator

A logarithm asks: to what power must the base be raised to give this number? This calculator shows the exact answer when there is one and the change of base calculation.

How to use it

  1. Enter the base and the number.
  2. See the exact power if it exists.
  3. Read the change of base working.

Example

log base 2 of 32 is 5, because 2⁵ = 32.

Common questions

What are the rules for the base and the number?

The base must be above 0 and not 1. The number must be above 0.

What is ln?

The natural logarithm, with base e.

What is the change of base formula?

log base b of x equals ln x divided by ln b.
