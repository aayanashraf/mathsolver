Pythagorean Theorem Calculator

Find a missing side of a right triangle.

About this calculator

In a right triangle, a² + b² = c², where c is the longest side. Leave one box empty and the calculator finds it, with the working.

How to use it

  1. Enter two sides.
  2. Leave the third box empty.
  3. Read the steps.

Example

a = 3 and b = 4: c² = 9 + 16 = 25, so c = 5.

Common questions

Which side is the hypotenuse?

The side opposite the right angle. It is always the longest.

Does it work for any triangle?

No, only for right triangles.

What if I know c and one leg?

Leave the other leg empty and it subtracts the squares.
