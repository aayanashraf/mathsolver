Permutation and Combination Calculator

Calculate nPr and nCr with factorial steps.

About this calculator

Permutations count arrangements where order matters. Combinations count selections where order does not matter. This calculator gives both and shows the factorials.

How to use it

  1. Enter n, the total number of items.
  2. Enter r, how many you choose.
  3. Compare nPr and nCr.

Example

n = 10, r = 3: nPr = 720 and nCr = 120.

Common questions

How do I know which one to use?

Ask whether swapping the order gives a different result. If yes, use a permutation. If no, use a combination.

Why is nCr smaller than nPr?

Each group of r items can be arranged in r! ways, and nCr counts each group only once.

What is the largest n allowed?

This tool accepts n up to 100.
