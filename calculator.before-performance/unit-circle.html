Unit Circle Calculator

Find the quadrant, reference angle, coordinates and exact sine, cosine and tangent of an angle.

About this calculator

The unit circle links angles to coordinates: the point at angle θ is (cos θ, sin θ). This calculator gives the coterminal angle, quadrant, reference angle and exact values for common angles.

How to use it

  1. Enter an angle in degrees.
  2. Read its quadrant and reference angle.
  3. See the coordinates and the exact values.

Example

150° is in quadrant II with reference angle 30°, so sin = 1/2 and cos = −√3/2.

Common questions

What is a reference angle?

The acute angle between the terminal side and the x-axis.

How do I know the signs?

Sine is positive in quadrants I and II. Cosine is positive in I and IV.

What is a coterminal angle?

An angle that ends on the same line, found by adding or subtracting 360°.
