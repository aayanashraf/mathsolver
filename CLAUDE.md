# MathSolveIQ project notes

Free math website for students. Name: MathSolveIQ.

## Rules
- Plain HTML, CSS and JavaScript. No framework unless asked.
- index.html holds the pages. Each page is <section class="page" id="page-NAME"> and has a link in the <nav> (href="#NAME").
- Styles in css/style.css, code in js/app.js. Keep light and dark mode working (CSS variables).
- Mobile first. Every page needs a title and a meta description.
- Tools that work without a server must stay client-side.
- Never put API keys in front-end files. Keys go in a .env file on the server only.
- After each change, tell me which files changed and how to test it.
